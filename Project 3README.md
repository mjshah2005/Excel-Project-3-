# 📊 Excel Data Analysis Project

## 🧾 Project Overview

This project contains an Excel workbook with multiple sheets focused on data analysis, reporting, and visualization. It demonstrates the use of Excel features for business insights and decision-making.

\---

## 📁 Sheets Description

### 1\. Raw Data

* Contains the original dataset
* Includes fields like Customer ID, Product, Region, Sales, Quantity, Date, etc.

### 2\. Data Cleaning

* Handles missing values
* Removes duplicates
* Standardizes formats

### 3\. Analysis

* Uses formulas like SUM, IF, INDEX-MATCH, etc.
* Performs calculations such as total sales, profit, and trends

### 4\. Pivot Tables

* Summarizes data by Region, Category, Customer
* Helps in quick insights generation

### 5\. Dashboard

* Visual representation of key metrics
* Includes charts like bar, line, pie charts
* Displays KPIs such as Total Revenue, Top Category, etc.
